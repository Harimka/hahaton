# Заметки по интеграции аппаратных драйверов

В данном документе описаны особенности работы с датчиком LSM6DS3 и модулем SD-карты на STM32G474RE.

## 1. Акселерометр LSM6DS3 (SPI2)
* **WHO_AM_I:** ожидаемое значение `0x69` (регистр `0x0F`).
* **Конфигурация:** ±16 g, ODR = 6.66 кГц.
* **Шина SPI2:** Mode 3, 8 бит, частота ~5.31 МГц (APB1 / 16).
* **FIFO:** Водяной знак (watermark) 16 XYZ. Согласно ST AN4650, после включения питания рекомендуется выждать не менее 2 мс перед активацией FIFO.

## 2. SD-карта по SPI (SPI3)
* **Шина SPI3:** Mode 0, инициализация на пониженной частоте ~332–400 кГц, затем переключение на ~5.31 МГц.
* **Поддержка:** SD v1/v2, SDHC/SDXC, чтение и запись блоков по 512 байт, проверка CRC16.
* **Файловая система:** Используется библиотека FatFs через адаптер `FatFsAdapter` (`firmware/Drivers/port/Src/fatfsadapter.cpp`).
