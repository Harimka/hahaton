# Руководство по работе с AI-ассистентами (Team-04)

> Памятка для участников команды: как ставить задачи своим ИИ (Cursor / Copilot / ChatGPT / Claude), чтобы получать рабочий и чистый код без поломки проекта.

---

## 1. Главные правила взаимодействия
1. **Каждый агент должен знать `AGENTS.md`:**  
   Перед началом любого промпта дайте агенту ссылку:
   > *"Внимательно прочитай файл AGENTS.md перед написанием кода."*
2. **Один модуль — один ответственный:**  
   Не просите нейросеть переписывать файлы других участников. Код пишется строго в рамках своей папки (`firmware/App/` или `firmware/Drivers/bsp/`).
3. **Требуйте `<scratchpad>` перед генерацией кода:**  
   Заставляйте нейросеть сначала расписать план и проверить ограничения:
   > *"Перед написанием кода выведи краткий план: какие структуры используешь, убедись, что нет malloc и HAL_Delay, и проверь Doxygen-шапку."*

---

## 2. Готовые промпты для каждого участника

### 👤 Участник 1 (Lead / FSM & Интеграция)
> *"Ты пишешь логику суперцикла и FSM в `firmware/App/Src/trigger_fsm.c`. Строго следуй интерфейсу `trigger_fsm.h`. Используй кольцевой статический буфер для сэмплов с предысторией. При превышении 3g переходи в захват, по спаду вычисляй границы кадра 0.25 * Amax. Никакого динамического выделения памяти."*

### 👤 Участник 2 (IMU LSM6DS3 + SPI DMA)
> *"Ты дорабатываешь драйвер LSM6DS3 в `firmware/Drivers/bsp/Src/lsm6ds3.c`. Взаимодействие с шиной идёт только через указатели функций в `bus_spi.h`. Никаких вызовов HAL_Delay() в цикле опроса. Чтение акселерометра должно быть неблокирующим."*

### 👤 Участник 3 (SRS Спектр)
> *"Ты отвечаешь за бортовой расчет спектра SRS в `firmware/App/Src/srs_smallwood.c`. Используй метод Смолвуда (Ramp Invariant) и предрассчитанные коэффициенты для 94 частот. Оптимизируй вычисления под FPU Cortex-M4F."*

### 👤 Участник 4 (SD-Карта и бинарный логгер)
> *"Ты реализуешь `firmware/App/Src/sd_logger.c`. Формируй бинарные файлы `raw_signal_XXXX.bin` и `raw_srs_XXXX.bin`. Запись производи блоками по 512 байт без вызова блокирующих задержек. Память под буферы выдели статически."*

### 👤 Участник 5 (Схемотехника & Python-скрипт)
> *"Ты разрабатываешь Python-скрипт `scripts/srs_analyzer.py` для парсинга bin-файлов в csv [t, ax, ay, az], расчета огибающей SRS и построения графиков. Для схемотехники: подготовь BOM и расчет баланса питания 12V Type-C + АКБ на 72 часа автономности в соответствии с требованиями ТЗ."*
