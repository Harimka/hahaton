# ARCHITECTURE & EMBEDDED C++ STANDARDS (ZT-Style)

> **Стандарт архитектуры, вдохновленный библиотеками `ztlib` и `ztgd32` из проекта `abs-3_console_fw`.**

---

## 1. Слои архитектуры и границы ответственности

```
┌────────────────────────────────────────────────────────┐
│ 1. APP LAYER (firmware/App/)                           │
│    - TriggerFsm, SrsSmallwood, DataLogger              │
│    - Чистая бизнес-логика и математика (FPU, DSP).     │
│    - ПРАВИЛО: Работает ТОЛЬКО с абстрактными           │
│      интерфейсами (ImuDrv, SpiDrv). 0 зависимостей     │
│      от STM32 HAL!                                    │
├────────────────────────────────────────────────────────┤
│ 2. DRIVER LAYER (firmware/Drivers/bsp/)                │
│    - lsm6ds3.cpp/.h (реализует ImuDrv)                 │
│    - sd_card.cpp/.h (реализует StorageDrv)             │
│    - ПРАВИЛО: Знает только регистры своего чипа. Все   │
│      операции с шиной передаются через SpiDrv.         │
│      НЕ знает конкретный микроконтроллер.              │
├────────────────────────────────────────────────────────┤
│ 3. PORT LAYER / MCU BSP (firmware/Drivers/port/)       │
│    - Stm32G4Spi (наследует SpiDrv, реализует HAL/LL)   │
│    - Stm32G4Gpio (управление CS пинами)                │
│    - ПРАВИЛО: Единственное место, где живет HAL/LL.    │
│      При замене STM32G4 на GD32F4/ESP32 меняется       │
│      ТОЛЬКО этот адаптер.                              │
└────────────────────────────────────────────────────────┘
```

## 2. Стандарты Embedded C++ (как в ztlib / abs-3)

1. **Язык:** Modern C++ (C++17). Использование классов, пространств имен и чистых интерфейсов (`virtual ... = 0`).
2. **Именование файлов:** Строго нижний регистр, слитное написание (`imudrv.h`, `serialdrv.h`, `spidrv.h`, `lsm6ds3.h`).
3. **Именование сущностей:**
   - Классы и структуры: `PascalCase` (`SerialDrv`, `ImuDrv`, `AccelData`).
   - Перечисления: `enum class` в `PascalCase`, значения с префиксом `k` (`kOk`, `kError`, `kTimeout`).
   - Константы: `static constexpr type kName = value;`.
   - Приватные поля классов: `camelCase_` с завершающим подчеркиванием (`bus_`, `isConfigured_`).
4. **Конструкторы (Leading Commas):**
   ```cpp
   Lsm6ds3::Lsm6ds3(SpiDrv& bus)
       : bus_(bus)
       , isReady_(false)
   {
   }
   ```
5. **Запрет копирования:** Для классов оборудования явно удалять конструкторы копирования и присваивания:
   ```cpp
   Lsm6ds3(const Lsm6ds3&) = delete;
   Lsm6ds3& operator=(const Lsm6ds3&) = delete;
   ```
6. **Zero Dynamic Allocation:** Категорический запрет на `new`, `delete`, `malloc`, `free`. Все экземпляры классов и кольцевые буферы создаются статически.
7. **Doxygen и английский язык:** Каждый файл начинается с Doxygen-шапки (80 символов) и заканчивается футером `/***************************** END OF FILE ************************************/`.
