# ARCHITECTURE & EMBEDDED DRIVER STANDARDS

## 1. Слои архитектуры и границы ответственности

```
┌────────────────────────────────────────────────────────┐
│ 1. APP LAYER (firmware/App/)                           │
│    - trigger_fsm.c / srs_smallwood.c                   │
│    - Чистая бизнес-логика и математика (FPU, DSP).     │
│    - ПРАВИЛО: 0 зависимостей от железа. Никаких HAL,   │
│      никаких регистров. Только абстрактные интерфейсы. │
├────────────────────────────────────────────────────────┤
│ 2. DRIVER LAYER (firmware/Drivers/bsp/)                │
│    - lsm6ds3.c, sd_spi.c, led.c                        │
│    - Законченные драйверы конкретных внешних чипов.    │
│    - ПРАВИЛО: Знают свои регистры чипа, но НЕ знают    │
│      микроконтроллер! Вся шина (SPI) дергается только   │
│      через абстрактный bus_spi.h.                      │
├────────────────────────────────────────────────────────┤
│ 3. BSP / PORT LAYER (firmware/Drivers/port/)           │
│    - stm32g4_spi_port.c, stm32g4_gpio.c                │
│    - Адаптер к конкретному МК (STM32 HAL / LL / DMA).  │
│    - ПРАВИЛО: Только здесь живут вызовы HAL_SPI / DMA! │
│      При замене STM32 на GD32/ESP32 меняется ТОЛЬКО этот│
│      слой. Слои 1 и 2 не меняются вообще.              │
└────────────────────────────────────────────────────────┘
```

## 2. Стандарты разработки embedded-драйверов
1. **Самодостаточность:** Драйвер обязан экспортировать законченный API (Init, Self-Test/WhoAmI, Config, Read, Write, Status) через структуры интерфейсов `sensor_imu.h` / `bus_spi.h`.
2. **Где живут регистры:**
   - Регистры внешнего чипа (LSM6DS3: `0x0F WHO_AM_I`, `0x10 CTRL1_XL`) объявляются строго в заголовочном файле драйвера (`lsm6ds3.h`) в виде `ALL_CAPS` макросов или enum.
   - Регистры микроконтроллера (SPI1_CR1, DMA1_Channel1) запрещены в драйверах — они инкапсулируются в слое BSP/Port.
3. **Zero-Copy и DMA-Ready:** Драйвер принимает и отдает заранее выделенные буферы вызывающей стороны. Никаких промежуточных копирований массивов.
4. **Статическая память:** Запрещены `malloc`/`free`. Экземпляры контекста драйвера аллоцируются статически.
5. **Неблокирующий опрос:** Драйвер не имеет права крутить циклы `while(!flag)` без тайм-аута или вызывать `HAL_Delay()`.
